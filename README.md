# Japanese Learning（日语学习）

> A bilingual, source-linked Japanese study workspace for Chinese-speaking learners.
> 面向中文学习者的日语学习资料库，保留原始资料链接，并为目录、课程和术语提供中文解释。

## Learning goals（学习目标）

- Build a solid foundation from JLPT N5 to N4（从 JLPT N5 到 N4 打好基础）.
- Follow the user's **新标准日本语（第二版）初级上、下册** study sequence where it fits（尽量与《新标准日本语》初级上、下册同步）.
- Learn vocabulary, grammar, listening, reading, speaking, and writing together（词汇、语法、听力、阅读、口语和写作同步推进）.
- Show kanji with furigana and provide Chinese translations（汉字尽量标注振假名，并附中文翻译）.
- Record the original source for every external course or learning resource（每份外部课程和资料都记录原始来源）.

## Recommended learning order（建议学习顺序）

1. Kana and pronunciation（五十音与发音）.
2. Core N5 vocabulary and textbook lessons（N5 高频词汇与教材课次）.
3. N5 particles, verb forms, and adjective forms（N5 助词、动词和形容词变形）.
4. Listening and short daily conversations（听力与日常短对话）.
5. N4 grammar and longer sentences（N4 语法与长句）.
6. Reading, writing, and JLPT practice（阅读、写作和 JLPT 练习）.

## Japanese notation standard（日语标注规范）

- Prefer ruby-style furigana above kanji where the display supports it, for example: `<ruby>日本<rt>にほん</rt></ruby>`.
- If ruby is unavailable, write `日本（にほん）`.
- Add a natural Chinese translation after each example sentence.
- Explain the grammar pattern, formation, meaning, usage, and common mistakes.
- For verbs, distinguish 一类动词、二类动词、三类动词（五段、上一段/下一段、不规则）.
- For adjectives, distinguish 一类形容词（い形容词） and 二类形容词（な形容词）.

## Lesson template（课程笔记模板）

Each lesson should contain:

1. Topic / 主题
2. Learning objectives / 学习目标
3. Vocabulary table / 词汇表（汉字、假名、词性、中文、例句）
4. Grammar explanation / 语法讲解（接续、含义、用法、易错点）
5. Example sentences / 例句（日文、振假名、中文）
6. Listening or speaking practice / 听力或口语练习
7. Exercises and answers / 练习题与答案
8. Sources / 资料来源
