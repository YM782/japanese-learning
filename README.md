# Japanese Learning（日語學習）

> A bilingual, source-linked Japanese study workspace.
> 中英／中日對照的日語學習資料庫，保留教材、課程與開源專案的原始來源。

## Learning Goals（學習目標）

- Build a solid foundation from JLPT N5 to N4（建立 JLPT N5 至 N4 的穩固基礎）。
- Follow 新標準日本語（第二版）初級上、下冊 where appropriate（盡量配合《新標準日本語》第二版初級上、下冊）。
- Study vocabulary, grammar, listening, reading, speaking, and writing（同步學習詞彙、語法、聽力、閱讀、口說與寫作）。
- Add furigana above kanji and provide Traditional Chinese translations（漢字盡量標註振假名，並提供繁體中文翻譯）。
- Preserve the original source link for every external resource（每份外部資料都保留原始來源連結）。

## Recommended Learning Order（建議學習順序）

1. Kana and pronunciation（五十音與發音）。
2. Core N5 vocabulary and textbook lessons（N5 高頻詞彙與教材課次）。
3. N5 particles, verb forms, and adjective forms（N5 助詞、動詞與形容詞變化）。
4. Listening and short daily conversations（聽力與日常短對話）。
5. N4 grammar and longer sentences（N4 語法與較長句型）。
6. Reading, writing, and JLPT practice（閱讀、寫作與 JLPT 練習）。

## Japanese Notation Standard（日語標註規範）

- Prefer ruby-style furigana above kanji where supported: `<ruby>日本<rt>にほん</rt></ruby>`.
- If ruby display is unavailable, use 日本（にほん）.
- Add a natural Traditional Chinese translation after each example sentence（每個例句後附自然的繁體中文翻譯）。
- Explain formation, meaning, usage, and common mistakes（說明接續方式、意思、用法與常見錯誤）。
- Distinguish 一類動詞、二類動詞、三類動詞（五段、上一段／下一段與不規則動詞）。
- Distinguish い形容詞 and な形容詞（い形容詞與な形容詞）。
