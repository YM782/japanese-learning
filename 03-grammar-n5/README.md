# JLPT N5 Grammar（N5 文法基礎）

本頁整理 N5 常見句型與活用規則。學習時請先理解句子中的角色，再記憶接續方式。

## 1. Basic Sentence Pattern（基本句型）

### A は B です

用來說明主題是什麼或具有什麼身分。

- 例句：私は学生（がくせい）です。
- 中文：我是學生。
- は：提示句子的主題，讀作 wa。
- です：禮貌體判斷句句尾。

### A は B ではありません

- 例句：私は先生（せんせい）ではありません。
- 中文：我不是老師。
- 口語也常見「じゃありません」。

### A は B ですか

- 例句：これは本（ほん）ですか。
- 中文：這是書嗎？

## 2. Core Particles（核心助詞）

| 助詞 | 主要功能 | 例句 | 中文 |
|---|---|---|---|
| は | 提示主題 | 私は学生です。 | 我是學生。 |
| が | 標示主語、焦點或新資訊 | 猫がいます。 | 有貓。 |
| を | 標示動作對象 | 水を飲みます。 | 喝水。 |
| に | 時間點、存在位置、目的地等 | 7時に起きます。 | 七點起床。 |
| へ | 移動方向，讀作 e | 学校へ行きます。 | 去學校。 |
| で | 動作場所、手段 | 図書館で勉強します。 | 在圖書館讀書。 |
| と | 和、與；引用 | 友達と話します。 | 和朋友說話。 |
| も | 也 | 私も行きます。 | 我也去。 |
| から | 起點、原因 | 9時から働きます。 | 從九點開始工作。 |
| まで | 終點 | 5時まで働きます。 | 工作到五點。 |

注意：は與が、に與で的差異要透過語境理解，不能只背單一中文翻譯。

## 3. Verb Groups（動詞分類）

- 一類動詞（五段動詞）：詞尾通常在う段，例如 書く、読む、話す、買う。
- 二類動詞（一段動詞）：常見為 る 結尾，前一個音多為い段或え段，例如 食べる、見る；但有例外。
- 三類動詞（不規則動詞）：する、来る（くる）。

## 4. Common Verb Forms（常用動詞變化）

以「書く、食べる、する、来る」為例：

| 形式 | 書く（一類） | 食べる（二類） | する（三類） | 来る（三類） |
|---|---|---|---|---|
| 辭書形 | 書く | 食べる | する | 来る |
| ます形 | 書きます | 食べます | します | 来ます（きます） |
| て形 | 書いて | 食べて | して | 来て（きて） |
| ない形 | 書かない | 食べない | しない | 来ない（こない） |
| た形 | 書いた | 食べた | した | 来た（きた） |

### 一類動詞的て形／た形規則

| 辭書形詞尾 | て形 | た形 | 例子 |
|---|---|---|---|
| う、つ、る | って | った | 買う→買って、待つ→待って |
| む、ぶ、ぬ | んで | んだ | 読む→読んで、遊ぶ→遊んで |
| く | いて | いた | 書く→書いて |
| ぐ | いで | いだ | 泳ぐ→泳いで |
| す | して | した | 話す→話して |

例外：行く（いく）→行って／行った。

### 一類動詞的ない形

將う段詞尾改成あ段，再加ない；う結尾改成わない。

- 書く → 書かない
- 読む → 読まない
- 話す → 話さない
- 買う → 買わない

## 5. Adjective Forms（形容詞變化）

### い形容詞：高い（たかい）

| 形式 | 變化 |
|---|---|
| 現在肯定 | 高い |
| 現在否定 | 高くない |
| 過去肯定 | 高かった |
| 過去否定 | 高くなかった |

例句：この本は高くないです。  
中文：這本書不貴。

### な形容詞：静か（しずか）

| 形式 | 變化 |
|---|---|
| 現在肯定 | 静かです |
| 現在否定 | 静かではありません |
| 過去肯定 | 静かでした |
| 過去否定 | 静かではありませんでした |

例句：この町は静かです。  
中文：這個城鎮很安靜。

注意：な形容詞修飾名詞時通常使用「な」，例如 静かな町（安靜的城鎮）。

## 6. Mini Exercises（小練習）

請選出正確答案：

1. 毎朝、水（　）飲みます。  
   A. は　B. を　C. に　D. で

2. 図書館（　）勉強します。  
   A. で　B. を　C. が　D. と

3. 「書く」的て形是哪一個？  
   A. 書って　B. 書いて　C. 書んで　D. 書きて

4. 「高い」的過去否定形是哪一個？  
   A. 高くない　B. 高いでした　C. 高くなかった　D. 高かったない

**答案：** 1-B、2-A、3-B、4-C。
