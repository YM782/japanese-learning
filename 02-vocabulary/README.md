# Japanese Vocabulary（日本語詞彙）

## 1. Vocabulary Card Format（單字卡格式）

每個單字至少記錄以下欄位：

| Field（欄位） | 說明 |
|---|---|
| Japanese（日本語） | 原文，保留漢字 |
| Furigana（振假名） | 漢字上方的平假名；若平台不支援，使用括號標註 |
| Part of Speech（詞性） | 名詞、動詞、い形容詞、な形容詞、副詞等 |
| Chinese（中文） | 繁體中文釋義 |
| Example（例句） | 自然的日語句子 |
| Translation（翻譯） | 繁體中文翻譯 |
| Audio（音訊） | 優先使用可靠詞典或原始教材音訊 |
| Memory Scene（情境記憶） | 以生活情境或幽默聯想幫助記憶 |

## 3. Example Cards（單字卡範例）

### 水（みず）— 水

- 詞性：名詞
- 例句：水（みず）を飲（の）みます。
- 中文：喝水。
- 記憶情境：運動完口渴到不行，第一件事就是找水喝。

### 食べる（たべる）— 吃

- 詞性：二類動詞（一段動詞）
- ます形：食べます
- て形：食べて
- ない形：食べない
- た形：食べた
- 例句：毎朝（まいあさ）パンを食（た）べます。
- 中文：每天早上吃麵包。

### 行く（いく）— 去

- 詞性：一類動詞（五段動詞）
- ます形：行きます
- て形：行って（注意：不是「行いて」）
- ない形：行かない
- た形：行った
- 例句：日曜日（にちようび）に図書館（としょかん）へ行（い）きます。
- 中文：星期日去圖書館。

## 4. Vocabulary Review（詞彙複習）

建議採用間隔複習：新學單字後，在第 1、3、7、14、30 天回顧。若忘記，縮短下次複習間隔。

每次複習可以採用四種方式：
1. 看日文說中文。
2. 看中文說日文。
3. 聽音訊寫出日文。
4. 用新單字造句。
